STEP 1페이지 구조와 공통 레이아웃

탐색(앱스토어형) → 상세(디스콰이엇형) → 외부 실행으로 이어지는 단순한 구조입니다. 회원 유형은 하나로 통합하고, 등록·관리 기능은 로그인한 모든 회원에게 열려 있어요.

  • 01홈
  • AI 통합 검색 · 추천 배너 · 트렌딩 · 최신
  • 02트렌딩산정 검토
  • 03인기 (하루/일주일/한 달)산정 검토
  • 04최신
  • 05팔로우 피드검토
  • —카테고리 (사이드바)

발견·이용 핵심

  • 07서비스 상세
  • 소개 · 리뷰 · 제작 이야기확장
  • —이용하기 → 외부 URL 새 탭
  • —좋아요 · 스크랩검토

공통 레이아웃

  • 글로벌 헤더 — 좌: 사이드바 버튼 + WEBTER 워드마크 / 우: 검색 · 서비스 등록 · 로그인(또는 프로필)
  • 메인 내비게이션 — 홈 | 트렌딩 | 인기 | 최신 | 팔로우 (목록형 페이지에서만 노출)
  • 사이드바 — 기본 접힘. 열면 콘텐츠 위로 오버레이(카테고리 8개 + 내 메뉴 2개). 메인 그리드 폭은 변하지 않음
  • 콘텐츠 — 최대 1376px, 좌우 32px. 카드 그리드 4열(1440) → 3열 → 2열 → 1열(390)
  • 푸터 — 슬로건, 팀 정보, 샘플 데이터 안내

공통 컴포넌트 재사용

  • 트렌딩·인기·최신·팔로우·카테고리 = 하나의 목록 레이아웃 + 정렬/필터만 다름
  • 등록·수정 = 하나의 서비스 폼
  • 모든 목록·검색·마이페이지·프로필 = 하나의 서비스 카드
  • 로그인 필요 동작(좋아요·스크랩·리뷰·팔로우) = 하나의 로그인 안내 모달

A서비스 탐색 및 이용
홈→트렌딩→서비스 상세→이용하기→외부 웹사이트(새 탭)
